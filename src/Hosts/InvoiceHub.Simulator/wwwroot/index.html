Invoice traffic

Invoices are generated, paid, go overdue; payments fail. Each step is a real command that commits the change and its event together.

Bulk export (claim-check)

A large file is written to blob storage; the event carries a small envelope with a size, a checksum and an expiring link.

Vendor catalogue import

An EDI 832 style file is imported; the import report (what was added, updated, rejected) is the claim-checked result.

Identity verifications (KYC)

The event carries ids only. The receiver pulls the details with an API key, and every read is audited.

Subscription renewals

Recurring revenue events: subscription.renewed.
